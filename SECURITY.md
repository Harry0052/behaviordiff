# Security

BehaviorDiff runs local demo builds against a synthetic seed. It does not take
credentials and it should not be pointed at a production database.

Report a vulnerability through GitHub private vulnerability reporting:

https://github.com/Harry0052/behaviordiff/security/advisories/new

Please include the version or commit, the command you ran, and the fixture if
it is synthetic. Do not include production data, credentials, or personal
information.
